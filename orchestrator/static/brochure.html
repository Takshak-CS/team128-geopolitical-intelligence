About the project

Built to find what no single source can.

Three decades of UN votes, bilateral trade records and live news events — run through four independent analytical models simultaneously, then cross-checked for contradictions. This is not a summary tool.

The problem

Every source shows you one lens. We show you four — and where they disagree.

Geopolitical analysis has a structural blind spot. If you look at trade data alone, you see economic dependencies. If you read today's news, you see today. If you query an LLM, you get a confident summary of things it was trained on — no dates, no primary sources, no way to know if it's describing 2019 or 2024.

None of these sources cross-check against each other. A country can be deeply economically intertwined with a bloc while voting against it at the UN every year. A bilateral relationship can look cooperative in the trade numbers while today's GDELT stream is showing its worst day in a decade. That gap — between what different data sources say about the same country — is the most valuable signal in geopolitical analysis. It's also the one that falls through the cracks of every existing tool.

"A divergence between trade structure and UN voting behaviour isn't noise — it's a structural tension that tells you which way a country might break under pressure."

This system was built to surface those divergences automatically, every time, for any country.

The idea

Four independent agents. One question. Where do they disagree?

The four agents — Soft Power, Policy Stance, Trade Intelligence and Event Summarization — each run entirely separate models on entirely separate datasets. They share only the question's plan: the country, as an ISO3 code, and the year. Everything else — the data and the method — is independent, and every answer comes back in one shared format so it can be compared.

The fusion engine then asks: what can we learn from the fact that these four independent systems are looking at the same country and coming to different conclusions? It runs six cross-agent rules, each testing a specific hypothesis that needs evidence from two independent sources.

The result is findings that no individual agent — and no summary-based tool — could produce:

What makes it different

This is not a language model. Every number has a source.

A general-purpose chatbot summarises text. Unless it searches the web, it works from its training data, and it rarely tells you which dataset or year a figure comes from. Ask it about India–China trade and it will give you a paragraph — without citing which BACI release, which year, which product sectors, or how much confidence the figure deserves.

Every output from this system is traceable. Each finding cites which agent produced it, which dataset it came from, which year the data covers, and what the confidence score was. The briefing shows the exact pipeline: plan → agent responses → fusion findings → narrative. You can see the working.

An LLM can tell you "India and China have complex trade relations." This system tells you: China carries 12.2% of India's total trade in 2024 (BACI, Trade agent, confidence 0.92); India trades inside the China-anchored bloc and the Policy Stance vote model also places it in China's UN bloc, with the caveat that its published label, Non-Aligned, is a manual override (corroboration, confidence 0.97); and on 22 Nov 2026 the pair's GDELT coverage was cooperative (mean Goldstein +2.9 over 11 events) against a broadly neutral 1990–2024 GGE baseline.

The four agents

What each one does and how

Soft Power Agent
Soft Power Index 2000–2024 · 5 dimensions · 195 states
  • A 0–100 composite of 23 indicators from 10 open datasets, weighted by principal component analysis rather than by hand
  • Score time series with Kalman filter smoothing, noise fitted per country — removes noise, preserves trend, gives a 95% interval for every year
  • Kalman forecast with confidence envelopes — not just a point estimate
  • SHAP attribution on an XGBoost, LightGBM and random-forest ensemble: which indicators drive a country's score, with the share taken by the score's own history stated separately
  • FAISS nearest-neighbour peers: the countries with the most similar indicator profile
  • Outputs: influence score with interval, trend direction, indicator drivers, forecast range, closest peer countries
Policy Stance Agent
UN GA votes 1989–2025 · UCDP conflict · 185 countries
  • Vote-similarity blocs: each country is placed in the bloc whose anchor countries it votes most like over a rolling 7-year window, and every placement states its basis (vote model, anchor country, manual override or fallback rule)
  • Louvain community detection: voting communities discovered from the vote graph with no labels at all, used to cross-check the anchor-based blocs
  • Topic-level vote agreement: who votes most and least like a country on resolutions about a topic, 1989–2025
  • UCDP conflict scoring: active conflict exposure and intensity
  • Graph attention network embeddings for the dashboard's network views
  • Outputs: bloc assignment with its basis, vote alignment rates, voting partners, conflict exposure
Trade Intelligence Agent
BACI bilateral trade 1995–2024 · 226 economies · 14 sectors and HS6 products
  • Network-based bloc detection (Louvain): trading blocs identified from flow data, not political categories
  • Critical partner dependence and leverage: which single relationship accounts for the most of a country's trade, and who depends on whom
  • Supply fragility by sector: how concentrated a country's import sourcing is in each of 14 sectors, such as energy, agriculture and electronics
  • Shock simulation: cascade a supply disruption through the full 226-node trade network
  • Forecasts of exports and imports: a linear trend, ARIMA or a hybrid of the two, picked for each series by back-tested error
Event Summarization Agent
GDELT live stream · GGE historical baseline 1990–2024
  • spaCy NER: turns noisy GDELT actor strings into attributable names, so events are credited to the right country pair
  • K-means theme clustering on CAMEO event root codes and Goldstein scores, validated against shuffled labels and across random seeds
  • Goldstein scale scoring: quantitative tone for each event and aggregated per bilateral pair
  • GGE baseline comparison: is today's tone out of character for this relationship's 1990–2024 history?
  • Source checks: each top event is checked against its source article, and events the article does not support are flagged as likely mis-tagged
  • Outputs: event count, Goldstein score, dominant themes, bilateral partner activity, baseline comparison, checked headlines; a 5-year day-by-day index answers history questions
Architecture

System design

Five FastAPI microservices, each containerised independently with Docker Compose. Caddy handles HTTPS termination via sslip.io — no domain needed. The orchestrator fans a question out in parallel to the agents its plan selects (usually all four), each under its own timeout, streams each result as it arrives via NDJSON chunked transfer (no WebSocket, no polling), then runs the fusion engine once every selected agent has answered or timed out. An agent that is down or slow is reported as missing; the rest still answer.

# POST /run → real-time NDJSON stream {"type": "plan", intent, iso3s, agents, time_window, severity} {"type": "agent", agent:"soft_power", result.insights[], result.envelope} ← arrives as it lands {"type": "agent", agent:"policy_stance", result.insights[], result.envelope} {"type": "agent", agent:"trade_intelligence", ...} {"type": "agent", agent:"event_summarization", ...} {"type": "fusion", fused.findings[], fused.stats, briefing, time_alignment} ← cross-agent output

Nine intent types are recognised: country_profile bilateral shock forecast blocs events ranking event_history vote_alignment. The intent parser extracts entities, time windows, severity and sector from free-form English and routes accordingly.

The key innovation

Cross-agent fusion: six rules, two independent sources each

Fusion is not averaging. Each rule tests a specific hypothesis that requires evidence from two independent sources — a finding neither could produce alone. Rules 1–4 run for each country in the question, Rule 5 for two-country questions and Rule 6 for shock scenarios; the results are ranked by confidence × kind weight × intent relevance.

Rule 1 — Bloc alignment

Compares the trading bloc anchor (Trade agent, from BACI flow analysis) against the UN bloc assignment (Policy Stance agent, from vote similarity to anchor countries, cross-checked by label-free Louvain communities). If country X trades inside a bloc but votes outside it, this is a divergence — a structural economic-diplomatic tension. If the bloc label is an assumption rather than a measurement, the finding carries that caveat.

TradePolicy Stance
Rule 2 — Critical partner across the bloc line

Checks whether the country's most critical trade dependency (Trade agent: highest-share partner), and its dominant supplier in each sector such as energy, sit in the same UN bloc as the country itself (Policy Stance agent). A country whose biggest trade partner votes on the other side of the UN is structurally exposed in a way that neither dataset reveals alone.

TradePolicy Stance
Rule 3 — Momentum agreement

Compares the trade trajectory direction (Trade agent: model-selected export or import forecast) against the soft power direction (Soft Power agent: Kalman-smoothed trend or 5-year outlook). Two completely independent models, different datasets, measuring different things. If both say "rising" or both say "falling", their confidences combine into a corroboration stronger than either alone; if they point opposite ways, it is a divergence.

TradeSoft Power
Rule 4 — Today's events vs. trade stakes and history

Takes the Goldstein score of today's GDELT events with the country's most critical trade partner (Events agent) and compares it against that partner's share of total trade (Trade agent). A conflictual day with your largest trade partner is a materially different signal from a conflictual day with a minor partner — but you need both datasets to know the difference. The same rule also sets the day's score for each of the most active pairs against the pair's GGE 1990–2024 baseline (a second, independent dataset): a cooperative news day in a historically tense relationship is as telling as the reverse.

EventsTrade
Rule 5 — Two countries: trade ties vs. votes

For a question about a pair: do the two share a trading bloc (Trade agent) and a UN bloc (Policy Stance agent)? Does the more dependent side rely on the relationship for at least 10% of its trade while the two vote alike on fewer than half of sampled resolutions? And is today's coverage between two UN-bloc partners conflictual (Events agent)?

TradePolicy StanceEvents
Rule 6 — Shock by diplomatic camp

For a shock scenario: of the economies most exposed to the cut (Trade agent, shock propagation), which vote in the origin country's own UN bloc and which in other blocs (Policy Stance agent)? A disruption that lands mostly on the other side of a bloc line is a different political event from one that hits allies.

TradePolicy Stance

Confidence arithmetic: corroborations combine as 1 − ∏(1 − cᵢ) (independent evidence strengthens the claim, capped at 0.97). Divergences and conjunctions take min(cᵢ) — only as solid as the weakest side. Findings are ranked by confidence × kind weight (divergence: 1.35, corroboration: 1.20, cross-agent: 1.10, single-agent claim: 1.0) × intent-relevance boost, which pushes contradictions between domains up the list. Cross-agent findings are listed before single-agent claims.

ML methods

Models used

Kalman filter — Soft Power agent

State-space smoothing on annual time series. Used for two tasks: noise reduction on historical scores, and forward forecasting with explicit uncertainty bounds. The filter's process noise and observation noise parameters are fit per country, so a country with volatile historical data gets wider envelopes. The width of that 95% interval also sets the confidence of each Soft Power claim.

Forecast model selection — Trade agent

For each export or import series, a linear trend, ARIMA(1,1,1) and a hybrid (linear trend plus ARIMA-modelled residuals) are back-tested from rolling origins, and the one with the lowest mean absolute percentage error is used. The series are annual, so no seasonal model is fitted.

SHAP (SHapley Additive exPlanations) — Soft Power agent

Attributes the ensemble's prediction of a country's score to its indicators, for example property rights. Because the score's own three-year history carries most of the attribution, the briefing lists the indicator drivers and states that share separately rather than presenting it as a driver.

FAISS nearest-neighbour search — Soft Power agent

Finds the countries whose standardised indicator profiles are closest by cosine similarity, shown as each country's peers.

Louvain community detection — Policy Stance & Trade agents

Modularity-maximising community detection. On the UN vote-similarity graph it finds voting communities from the data alone, with no labels or anchor countries; the orchestrator compares them with the anchor-based blocs (Western Bloc, Russia+Allies, China-Centered Bloc, Non-Aligned) and attaches a caveat where they disagree. On the trade graph it finds trading blocs, with a fixed seed so results are reproducible.

Graph attention network — Policy Stance agent

A two-layer graph attention network learns country embeddings from the conflict and vote-agreement graph for the dashboard's network views, with a random-walk embedding as a fallback. Bloc assignment itself comes from vote similarity to anchor countries, not from these embeddings.

K-means with silhouette validation — Events agent

Groups a day's events into themes using each event's CAMEO root code and Goldstein score. The fit is checked with the silhouette score against shuffled labels and for stability across random seeds, and the briefing states that check next to the themes.

spaCy NER — Event Summarization agent

Named entity recognition turns GDELT's noisy actor strings into attributable names, so events are credited to the right country pair. Required because GDELT CAMEO actor codes are often incomplete or ambiguous at the sub-national level.

Source-article checks — Events, no AI model

Each of the day's top events is checked against its source article: are both actors named in one descriptive sentence? Events the article does not support are reported as likely mis-tagged by GDELT, never as news.

Infrastructure

Deployment

Docker Compose with six services: orchestrator (FastAPI, port 8000), soft power (FastAPI, port 8101), policy stance (FastAPI, port 8102), trade intelligence (FastAPI, port 8103), event summarization (FastAPI, port 8104), and Caddy as the HTTPS reverse proxy. Caddy uses sslip.io for TLS certificate issuance — no domain purchase required.

Each agent service exposes its own REST API and a React/Vite dashboard served by Caddy directly. The orchestrator serves the site's HTML pages (home, features, engine and this page) as static files. Streaming uses chunked transfer encoding with Cache-Control: no-cache, no-transform and X-Accel-Buffering: no to prevent proxy buffering.
